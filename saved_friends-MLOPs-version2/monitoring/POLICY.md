# Monitoring and retraining policy

Monitor latest 1,000 requests; at least 100 feature rows for PSI and 100 verified delayed labels for MAE. Data drift: any feature PSI >=0.20. Quality degradation: MAE >max(5 minutes, 1.2 × frozen validation MAE). A changed P(y|X) can cause that signal, but degraded MAE alone does not prove concept drift. Inspect label validity, routes, traffic and seasonal shifts before diagnosing it.

The monitoring loop runs every 60 seconds. Two non-overlapping windows with at least 100 new label rows each create `retrain_request.json`. Registry name and version identify the active model; older versions are excluded. The last completed quality result remains visible while new labels accumulate. Label verification is operational and is not enforced by the demo endpoint. Supply fresh labels and preserve chronological train/validation/new test. The pipeline compares a candidate with the currently approved file on the same validation data, rejects worse MAE before test/registration, and then applies absolute/dummy/HTTP gates. Fresh business data and human production approval are not supplied automatically. The isolated synthetic cycle uses real container HTTP/restart/rollback; it is not evidence of production retraining.

Prometheus alert rules cover availability, model readiness, server error rate >1%, p95 processing latency >1 second, data drift and quality. HTTP benchmark measures client end-to-end latency; histogram measures processing time. Actual scraping and data/quality firing states passed in Docker (evidence/container_drift_alerts.json). System-down firing is tested separately. No Alertmanager receiver or outbound notification to a person is configured or tested.

SQLite keeps derived features, predictions, model version, request time and later feedback. Avoid exact coordinates and personal IDs in logs. Retain 7 days in a pilot; implement deletion/access controls before deployment. The current code does not enforce retention, authentication or label provenance. Feedback in demos is trusted synthetic/test data. A production feedback endpoint must verify label sources.
